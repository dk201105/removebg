Developer REST API

Integrate our background removal into your backends, build pipelines, or mobile apps. The endpoint accepts multi-part form uploads and returns crisp transparent PNG or WebP images.

curl -X POST https://api.erase.tools/v1/remove \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "image=@portrait.jpg" \
  -F "quality=ultra" \
  -F "subject=person" \
  -o cutout.png
import requests

url = "https://api.erase.tools/v1/remove"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
data = {"quality": "ultra", "subject": "product"}

with open("product.jpg", "rb") as f:
    response = requests.post(url, headers=headers, data=data, files={"image": f})
    if response.status_code == 200:
        with open("product-no-bg.png", "wb") as out:
            out.write(response.content)
import fs from 'node:fs';
import FormData from 'form-data';
import fetch from 'node-fetch';

const form = new FormData();
form.append('image', fs.createReadStream('photo.jpg'));
form.append('quality', 'ultra');

const res = await fetch('https://api.erase.tools/v1/remove', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
  body: form
});

const buffer = await res.buffer();
fs.writeFileSync('cutout.png', buffer);

Data Retention & Privacy Policy

100% Client-Side Processing Guarantee

When using Erase with the default local engine, your images are decoded, segmented, and refined entirely inside your browser using WebGPU and WebAssembly. Zero bytes of image data leave your device.

0-Second Data Retention
Because photos are processed in local memory, no temporary files or thumbnails are ever stored on any remote server. Once you close or reload the browser tab, in-memory image allocations are discarded.

Zero AI Model Training
Your photos are never viewed, collected, logged, or used to train, test, or fine-tune machine learning models.

Local Storage and History
If you use the optional "History" drawer, thumbnails are saved strictly within your browser's private IndexedDB sandbox on your personal device. You can clear this storage at any time with a single click.
